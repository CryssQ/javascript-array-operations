# JavaScript Array Tasks

A collection of JavaScript exercises focused on working with arrays.

## 📚 Tasks

### 1. Count and Sum Even Numbers

Count the number of even elements and calculate their sum within a given range.

### 2. Average and Greater Elements

Calculate the arithmetic mean of an array and count the elements that are greater than the average.

### 3. Sum of Two Arrays

Create a third array by adding corresponding elements of two arrays of the same length.

### 4. Array Concatenation

Create a third array by concatenating two arrays of different lengths.

### 5. Swap Min and Max

Find the minimum and maximum elements and swap their positions in the array.

### 6. Split Positive and Negative

Split an array into two arrays:
- positive elements
- negative elements

### 7. Remove Duplicate Min and Max

Remove duplicate occurrences of the minimum and maximum elements while keeping one occurrence of each.

### 8. Average of Two Arrays

Calculate the arithmetic mean of two arrays and create a third array containing elements that are within the range between the two average values.
